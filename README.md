# Form Validation

Клиентская валидация формы с полями email и пароль.

## Задача
Дана HTML-форма с полями email и пароль, плюс кнопка «Отправить». При клике на кнопку:

- предотвратить обычную отправку формы;
- проверить, что email содержит символ `@`, пароль не короче 6 символов;
- при ошибке показать сообщение под полем, при успехе — показать сообщение об успешной отправке.

## Что реализовано
- Форма с атрибутом `novalidate` — отключает встроенную браузерную валидацию, чтобы контролировать её вручную.
- Поля email и password с `name`, `type`, `placeholder`, `required`, `minlength`.
- Отдельные контейнеры для сообщений об ошибках под каждым полем.
- Обработчик события `submit` на форме.
- `event.preventDefault()` — отмена стандартной отправки формы и перезагрузки страницы.
- Очистка всех сообщений перед каждой новой валидацией.
- Проверка email через `String.prototype.includes("@")`.
- Проверка длины пароля через `String.prototype.length`.
- Флаг `success` для накопления результата — форма проходит только если все проверки успешны.
- Ранний выход `return` при ошибке — успешный сценарий не выполняется.
- Вывод сообщений через `textContent` — безопасно, без парсинга HTML.
- Сброс формы после успешной отправки через `form.reset()`.

## Технологии
- HTML
- JavaScript
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.
3. Попробовать отправить форму с разными данными.

## Структура проекта
```
├── index.html   — разметка: форма, поля, контейнеры ошибок и результата
├── index.css    — стили для классов .error и .ok (по желанию)
└── app.js       — валидация и обработка события submit
```
